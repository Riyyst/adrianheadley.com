Website information

Security & Trust

How the Adrian Headley portfolio is operated, what external services it uses, and how to report a security concern or incorrect website classification.

Operator and purpose

adrianheadley.com is a personal portfolio operated by Adrian Headley. Its purpose is to present professional experience, projects, articles, qualifications, business work and contact information.

The site does not require visitors to create an account or sign in.

Privacy and data handling

The site uses Google Analytics to measure aggregate traffic, popular pages and general site usage. It does not display advertising or intentionally load advertising trackers. Most portfolio content is delivered as static pages.

The contact form uses Formspree only when a visitor chooses to submit a message. Accessibility preferences are stored locally in the browser and may use a first-party preference cookie. The Privacy page explains this in more detail.

External services and links

The portfolio contains links to independent project sites, research sources, qualification providers, social networks and other external services. Following those links takes you outside adrianheadley.com and the destination may use its own security, privacy or tracking systems.

External content is not embedded merely for advertising purposes, and the portfolio does not intentionally install software or trigger unsolicited downloads.

Downloads and generated files

Where the site offers a document such as a CV, the file is opened or downloaded only after the visitor chooses the relevant action. The portfolio does not ask visitors to run installers or executable software.

Report a security issue

If you believe you have found a vulnerability, compromised page, unsafe behaviour, malicious redirect or incorrect security classification, please report it through the contact form. Include the affected URL, what you observed and enough detail to reproduce the issue where it is safe to do so.

Please do not send passwords, private keys, access tokens, confidential records or other unnecessary sensitive information.

A machine-readable vulnerability disclosure file is published at /.well-known/security.txt.

Search, antivirus and web-filter classification

Search engines, antivirus products, secure web gateways and web filters maintain independent reputation and categorisation systems. Their classifications can differ, particularly for personal domains, newer subdomains or sites that link to technical projects.

This page, the Privacy page, Terms of Use, sitemap, robots directives and security.txt file are published to give people and automated reviewers a clear description of the site’s operator, purpose and data flows.

No website can control how an independent filtering provider categorises a domain, but incorrect classifications can be reviewed by the provider using this information.

Changes to this page

This page may be updated as the portfolio, its hosting or its external integrations change.
